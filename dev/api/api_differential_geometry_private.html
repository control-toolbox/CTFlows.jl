Private API

This page lists non-exported (internal) symbols of CTFlows.DifferentialGeometry.

From CTFlows.DifferentialGeometry

Ad

CTFlows.DifferentialGeometry.Ad — Type
struct Ad{TX, TF, B<:CTFlows.Differentiation.AbstractADBackend, TD, VD} <: Function

Callable struct representing the Lie derivative or Lie bracket of foo along X.

  • Scalar foo: Lie derivative ∇foo(x)'·X(x) — first JVP, no second pass.
  • Vector foo: Lie bracket J_foo(x)·X(x) - J_X(x)·foo(x) — two JVPs via Differentiation.pushforward, eliminating the per-call inner closures (X̂ = x_->X(x_), f̂ = x_->foo(x_), g(s) = f̂(x+s·X_x)) that the old closure-based _ad created on every evaluation.

TD and VD are compile-time trait parameters so the correct call method (and slot numbering) is resolved statically.

DG_AD_BACKEND

CTFlows.DifferentialGeometry.DG_AD_BACKEND — Constant

Global reference to the automatic differentiation backend used by DifferentialGeometry operations.

This Ref holds the current AD backend that is used by CTFlows.DifferentialGeometry.ad, CTFlows.DifferentialGeometry.Poisson, and CTFlows.DifferentialGeometry.∂ₜ when no explicit ad_backend keyword argument is provided.

Type

  • Ref{Differentiation.AbstractADBackend}: Mutable reference to an AD backend.

Notes

  • Initialized at module load time with AutoForwardDiff via CTFlows.Differentiation.build_ad_backend.
  • Modified via CTFlows.DifferentialGeometry.dg_ad_backend!.
  • Accessed via CTFlows.DifferentialGeometry.dg_ad_backend.

See also: CTFlows.DifferentialGeometry.dg_ad_backend, CTFlows.DifferentialGeometry.dg_ad_backend!, CTFlows.DifferentialGeometry.__dg_ad_backend.

DIFFGEO_PREFIX

CTFlows.DifferentialGeometry.DIFFGEO_PREFIX — Constant

Prefix reference for the CTFlows package used in @Lie macro generated code.

This Ref stores the symbol of the root package that the @Lie macro uses to qualify generated function calls (e.g., CTFlows.DifferentialGeometry._lie_mac).

E_PREFIX

CTFlows.DifferentialGeometry.E_PREFIX — Constant

Prefix reference for the exception-handling module used in @Lie generated code.

This Ref stores the symbol of the module that defines the IncorrectArgument type thrown by the @Lie macro at expansion time.

PoissonBracket

CTFlows.DifferentialGeometry.PoissonBracket — Type
struct PoissonBracket{FH, FG, B<:CTFlows.Differentiation.AbstractADBackend, TD, VD} <: Function

Callable struct representing the Poisson bracket {H, G} = ∇ₚH'∇ₓG - ∇ₓH'∇ₚG.

Replaces the four closures previously returned by _Poisson. TD and VD are compile-time trait parameters so the correct call method is resolved statically. Partial derivatives are computed via Differentiation.differentiate, which uses WithActiveArg internally — no per-call closure allocation.

TimeDeriv_F

CTFlows.DifferentialGeometry.TimeDeriv_F — Type
struct TimeDeriv_F{F, B<:CTFlows.Differentiation.AbstractADBackend} <: Function

Callable struct for ∂ₜ(f::Function) — time derivative of a generic callable.

Replaces the outer closure (t, args...) -> Differentiation.derivative(b, s -> f(s, args...), t).

TimeDeriv_Ham

CTFlows.DifferentialGeometry.TimeDeriv_Ham — Type
struct TimeDeriv_Ham{FH, B<:CTFlows.Differentiation.AbstractADBackend, TD, VD} <: Function

Callable struct for ∂ₜ(H::AbstractHamiltonian).

  • Autonomous: ∂H/∂t = 0; returns zero(H(...)) without AD.
  • NonAutonomous: differentiates H w.r.t. slot 1 (time) via Differentiation.differentiate.

TimeDeriv_VF

CTFlows.DifferentialGeometry.TimeDeriv_VF — Type
struct TimeDeriv_VF{FX, B<:CTFlows.Differentiation.AbstractADBackend, TD, VD} <: Function

Callable struct for ∂ₜ(X::AbstractVectorField).

  • Autonomous: ∂X/∂t = 0; returns zero.(X(...)) without AD.
  • NonAutonomous: differentiates X w.r.t. slot 1 (time) via Differentiation.differentiate.

_Bracketable

CTFlows.DifferentialGeometry._Bracketable — Type

Type alias for operands that support Lie bracket computation.

Unifies Function and AbstractVectorField for dispatch in the @Lie macro and related operations. This enables consistent handling of both raw functions and wrapped vector fields in Lie bracket computations.

Notes

  • Used internally by CTFlows.DifferentialGeometry._lie_mac for runtime dispatch.
  • Functions are normalized to VectorField before actual computation.

See also: CTFlows.DifferentialGeometry.@Lie, CTFlows.DifferentialGeometry.ad, CTFlows.Data.AbstractVectorField.

_Poissonable

CTFlows.DifferentialGeometry._Poissonable — Type

Type alias for operands that support Poisson bracket computation.

Unifies Function and AbstractHamiltonian for dispatch in the @Lie macro and related operations. This enables consistent handling of both raw functions and wrapped Hamiltonians in Poisson bracket computations.

Notes

  • Used internally by CTFlows.DifferentialGeometry._poisson_mac for runtime dispatch.

See also: CTFlows.DifferentialGeometry.@Lie, CTFlows.DifferentialGeometry.Poisson, CTFlows.Data.AbstractHamiltonian.

__dg_ad_backend

CTFlows.DifferentialGeometry.__dg_ad_backend — Function
__dg_ad_backend() -> CTFlows.Common.NotProvided

Return the sentinel value indicating no AD backend was explicitly provided.

This function is used as the default value for the ad_backend keyword argument in DifferentialGeometry operations. When returned, the global backend DG_AD_BACKEND is used instead.

Returns

  • Common.NotProvided: Sentinel value indicating backend should use global default.

Notes

  • This is an internal function used by CTFlows.DifferentialGeometry._resolve_backend.
  • Users should use CTFlows.DifferentialGeometry.dg_ad_backend to get the current backend.

See also: CTFlows.DifferentialGeometry.DG_AD_BACKEND, CTFlows.DifferentialGeometry._resolve_backend.

_check_not_hvf

CTFlows.DifferentialGeometry._check_not_hvf — Function

Check that vector field is not a HamiltonianVectorField (runtime check).

Arguments

  • ::Data.AbstractVectorField: Plain vector field (allowed).

Returns

  • nothing

Throw NotImplemented if vector field is a HamiltonianVectorField.

HamiltonianVectorFields have signature (x, p) not (x), so they cannot be used with the Lie bracket operations on plain vector fields.

Arguments

  • X::Data.AbstractHamiltonianVectorField: Hamiltonian vector field (not allowed).

Throws

  • Exceptions.NotImplemented: Always thrown for HamiltonianVectorFields.
